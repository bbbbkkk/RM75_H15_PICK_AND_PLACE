# RM75 + H15 三层积木操控

[English](README_EN.md)

这个 Demo 的目标是让睿尔曼 RM75 带动 PaXini H15，用拇指、食指和中指搭建和重排一座三层积木塔。首版方案选用三块同边长的红、蓝、紫色积木。Python 应用直接调用厂家 SDK，通过固定 RGB-D 相机测量积木位置，以指腹触觉和短程试提判断抓取是否可靠。

**当前进度**：已完成开发规格和验收方案。下表描述计划实现的真机行为。首次联调从“抓一块、试提、放到空位、撤手复测”开始，实机节拍和成功率待测。

| 演示任务 | 预期行为 |
|---|---|
| 按序堆叠 | 依次放下三块积木。放上层前，重新测量下层的实际顶面；下层平稳且偏移在容差内时，上层目标随之更新。 |
| 移除、拆塔与换层 | 例如要移除中层蓝块，先暂存顶层紫块，取出蓝块，再把紫块放回红块上。换层和拆塔复用同一套单块抓放动作。 |
| 掉块恢复 | 暂停搬运，重新观察掉块和可能受影响的塔层。位置清楚且可达时重新抓取，也可以由操作员把木块放入恢复区，再继续剩余步骤。 |

**相机与触觉如何配合。** 固定 RGB-D 负责全局定位，也在撤手后检查落点和层高。H15 自带普通 RGB 相机，预抓时可取一张新图检查对准情况，需要时修正一次并复拍。三指闭合后先短程试提，确认保持夹持才开始横向搬运。标定工具独立运行，每台启用几何定位的相机采 35 个有效姿态，30 个用于求解，5 个用于独立验证。

**开发入口。** 业务代码归入 `src/`，工位参数和当前标定结果归入 `config/`。`src/app.py` 负责 Python 界面，`src/tasks.py` 决定搬哪块，`src/pick_place.py` 执行一次搬运。设备、视觉、场景记录和标定分别归入 `src/devices.py`、`src/vision.py`、`src/scene.py`、`src/calibrate.py`。
